# maus-downloader
downloads sendung mit der maus seasons just by running `maus-downloader --urls=url1,url2,url3` from the official sendung mit der maus website. Episode(s) will be downloaded to current dir. This project is a private proof of concept created for educational and testing purposes only. All rights to the referenced content (e.g. Sendung mit der Maus) remain with their respective copyright holders. 

## Build
Just run `go build` in dir in order to create maus-downloader executable.
